# Windows

Windows is het meest voorkomende doelwit en tegelijk de belangrijkste bron van telemetrie. Deze sectie behandelt de onderdelen die je bij triage en hardening vaak tegenkomt.

## Onderwerpen

| Pagina | Inhoud | Wanneer gebruiken |
| :--- | :--- | :--- |
| [Windows CLI Basics](/windows/windows-cli-basics) | CMD-commando's voor navigatie, bestanden, systeem en netwerk | Eerste verkenning van een systeem |
| [Windows File System](/windows/windows-file-system-basics) | NTFS, standaardmappen, Alternate Data Streams, persistence-plekken | Forensische controle en triage |
| [Windows Services](/windows/windows-services) | Servicebeheer en attack vectors zoals unquoted service paths | Privilege escalation en persistence |
| [Active Directory](/windows/active-directory-basics) | Forest, domein, OU's, groepen en AGDLP | Beheer en enumeratie-detectie |
| [Group Policy](/windows/group-policy-basics) | GPO-hiërarchie, `gpresult`, hardening | Beleid afdwingen en troubleshooten |

## Leerpad

1. Start met [Windows CLI Basics](/windows/windows-cli-basics) en [Windows File System](/windows/windows-file-system-basics).
2. Vervolg met [Windows Services](/windows/windows-services) om te zien hoe persistence en privilege escalation werken.
3. Ga daarna naar [Active Directory](/windows/active-directory-basics) en [Group Policy](/windows/group-policy-basics).
