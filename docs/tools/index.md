# Tools

Tools voor netwerkanalyse en verkenning. Gebruik ze alleen op systemen waarvoor je toestemming hebt.

## Onderwerpen

| Tool | Doel | Typisch gebruik |
| :--- | :--- | :--- |
| [Wireshark](/tools/wireshark-basics) | Pakketanalyse en protocoldecodering | Verdacht verkeer onderzoeken in een capture |
| [Nmap](/tools/nmap-basics) | Host discovery en poortscanning | Inventariseren welke diensten bereikbaar zijn |

## Kiezen tussen de twee

- **Wireshark** kijkt naar bestaand verkeer en laat zien wat er daadwerkelijk over de lijn gaat.
- **Nmap** stuurt zelf pakketten om te achterhalen wat een host aanbiedt.
